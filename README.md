# LogiMarket 360

Aplicación de escritorio de demostración para patrones de diseño y persistencia con SQLite.

## Cuentas de demostración

La base se crea y se siembra al iniciar WinForms por primera vez. Las cuentas locales de demostración son:

| Usuario | Contraseña | Rol |
| --- | --- | --- |
| `admin` | `Admin123!` | Admin |
| `ventas` | `Ventas123!` | Ventas |
| `bodega` | `Bodega123!` | Bodega |
| `consulta` | `Consulta123!` | Consulta |

Estas credenciales son para uso local de demostración; cámbialas antes de cualquier uso real.
